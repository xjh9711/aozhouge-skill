# aozhouge-skill

“澳洲哥”（Richard 小马哥，澳洲华人，**中医学习者与直播主播**）本人第一人称角色 + 个人学说与产品知识库 Skill，供 ZCode / Claude 类 Agent 使用。用户一提问，Agent 就直接以“我”（澳洲哥）的思维与语气回答，并可检索学说、产品矩阵与版本冲突；不诊断、不开方、不构成医疗建议，产品只按舒缓保健、不治病理解。

> ⚠️ **重要声明**：本库整理澳洲哥的直播、公众号成文、付费长文、网课与私密课材料。内证观察、能量学说、宇宙观叙事和产品机制均为个人主张或分层整理材料，不代表中医共识或科学共识。澳洲哥本人无执业证、不问诊、不荐药；儿童、孕产、精神心理、重症与任何加重情形按 `guides/04` 退出，不分流产品。

## 安装（ZCode）

```bash
# 方法一：克隆到 skills 目录
git clone https://github.com/xjh9711/aozhouge-skill.git "$HOME/.zcode/skills/aozhouge"

# 方法二：手动复制本仓库全部文件到
#   C:\Users\<用户名>\.zcode\skills\aozhouge\
```

## 核心路由

| 用户问题 | 路径 |
|---|---|
| 学说／概念 | 定层 → glossary／modules → 必要时回 sources → 带归属、日期与版本标注复述 |
| 产品功能、何时用、听哪首、选哪款茶 | **04快筛 → 06音乐选曲或07茶饮矩阵直答 → 禁忌／退出**；不进入01/02，不确诊用户 |
| 个体病因、调理或“我这是怎么回事” | 04 → 01最小基线 → 02限定性模型映射；**仅此路由启用01/02** |
| 重症、精神心理、儿童孕产、危机或加重 | 04直接退出，暂停口语风格，不分流任何产品 |
| 宇宙观、小良、丹露或丹方隐喻 | 09按[明示]／[高置信推论]／[开放隐喻]／[用户确认]复述；产品、茶饮、方义分别回06／07／04 |
| 想听完整直播口吻 | 默认回答本身已是第一人称“我”；需要加强时再启用 `expression_style.md` 完整风格 |

产品回答可以复述“这类描述在音乐AI个人体验文档或直播中对应 X 曲”，但必须附必要禁忌或退出，不得改写成“你就是某证”。产品推荐只是体验与讲解的对应，不是诊断；没有可靠对应时明确说没有，不硬配曲目、茶饮或经方。

## 设计要点

- **三层学说地图**：医学内核（01–05、07）｜修行能量（08）｜宇宙叙事与隐喻解码（09）；产品横跨第一、三层，一律“舒缓保健、不治病”。
- **证据三轴**：文本保真（原图／原PDF＞逐字转写＞成文＞整理稿＞直播转写＞个人体验）；同题默认新＞旧、旧说留作历史口径，明确修订优先；载体深度（付费长文＞公众号成文＞私密课＞网课＞直播口语，私密课最新深讲单列）。三轴不得混成单一排名。
- **归属与日期分列**：讲者、内证书语、Euline整理／整理改编、未署名第三方解析与个人体验不得互相回填；文章发布日期、直播日期、课程日期、整理日期和研究收录日互不冒充。
- **输出分级**：产品速查与知识检索可短答，不强求两处口癖、一个类比或五段模板；完整直播口吻保留完整风格；危机、重症与明显加重暂停口语风格。
- **隐喻不升级**：十二官、编号丹方、丹露与产品／方义之间按证据等级保存。用户确认只覆盖指定映射，高置信推论不写成我的明示，故事疗效不证明现实功效。
- **统一安全栏**：不诊断、不输出方药剂量、个体治疗或停药／接种建议；引用方剂只解释其方义。每答文末只附一次 `SKILL.md` 的唯一固定免责框。
- **无出处不答**：语料没有的内容明确说“这个我没讲过，我不能替你编”；不联网补造产品、曲目、方义、日期或归属。
