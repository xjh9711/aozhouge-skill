# aozhouge-skill

"澳洲哥"（Richard 小马哥，澳洲华人中医主播）个人学说的知识库 Skill，供 ZCode / Claude 类 Agent 使用：既可**检索其学说内容**，也能以**澳洲哥的说话风格**（口语+理工类比+声明式免责）回答问题。

> ⚠️ **重要声明**：本库内容整理自其 2026 年 2-10 月共 76 场直播的文字稿与私密课整理稿，全部为**其个人学说**，不代表中医共识或科学共识；其中大量主张（内证观察、能量学说、宇宙观叙事等）不可验证。本项目仅作知识整理与学习交流，**不构成任何医疗建议**。

## 安装（ZCode）

```bash
# 方法一：克隆到 skills 目录
git clone https://github.com/xjh9711/aozhouge-skill.git "$HOME/.zcode/skills/aozhouge"

# 方法二：手动复制本仓库全部文件到
#   C:\Users\<用户名>\.zcode\skills\aozhouge\
```

安装后新会话中提到"澳洲哥 / 内证观察 / 一人一方 / 经络音乐"等触发词即可激活；也可 `/aozhouge` 显式调用。

## 设计要点（与"倪海厦 skill"同源的方法论）

- **三层学说标注**：`[内证断言]` / `[中西汇通解释]` / `[叙事]` / `[产品主张]` —— 每条论断自带性质标签，防止把个人学说当共识输出。
- **场次溯源**：论断标注来源场次（如〔2026-03-01 经络实质场〕），可回溯到对应直播。
- **原话保真**：引用其直播原话（含口癖），只截取不改写。
- **医疗红线**：全库不输出处方级建议；继承他本人"无证不问诊不荐药"的边界；每答文末固定免责框。
