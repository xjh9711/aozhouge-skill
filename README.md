# aozhouge-skill

"澳洲哥"（Richard 小马哥，澳洲华人中医主播）个人学说的知识库 Skill，供 ZCode / Claude 类 Agent 使用：既可**检索其学说内容**，也能以**澳洲哥的说话风格**（口语+理工类比+声明式免责）回答问题；通过 `guides/` 应用层，还可在风险筛查与证据边界内进行**限定性自我观察、身体问题的模型映射和官方低风险产品说明**，不作诊断或个体治疗。

> ⚠️ **重要声明**：本库内容整理自其 2026 年 2-10 月共 76 场直播、公众号成文、网课与私密课整理稿，另收录 2026-11-04 与 2026-11-06 两份直播 AI 转写整理与解析稿（非逐字、未经讲者审定），全部为**其个人学说及分层整理材料**，不代表中医共识或科学共识；其中大量主张（内证观察、能量学说、宇宙观叙事等）不可验证。本项目仅作知识整理与学习交流，**不构成任何医疗建议**。

## 安装（ZCode）

```bash

git clone https://github.com/xjh9711/aozhouge-skill.git "$HOME/.zcode/skills/aozhouge"

# 方法二：手动复制本仓库全部文件到
#   C:\Users\<用户名>\.zcode\skills\aozhouge\
```

## 设计要点（与"倪海厦 skill"同源的方法论）

- **三层学说标注**：`[内证断言]` / `[中西汇通解释]` / `[叙事]` / `[产品主张]` —— 每条论断自带性质标签，防止把个人学说当共识输出。
- **来源与证据分级**：已对图核验的付费公众号全文为最高权重一手长文，其后为其他公众号成文→网课/私密课（第三方双视角另标）→直播转写。原始 PDF 页图＞OCR 检索底稿＞既有模块总结；调用时仍先查模块。两场直播 AI 转写整理稿不冒充审定逐字稿，解析层不归讲者。
- **逐篇归属与日期并列**：首页“原创 澳洲哥”不统称逐字亲笔，讲述、Euline 整理/整理改编逐篇区分；新增两场讲稿的整理者／解析者均未署名，不回填 Euline。仅明确修订/勘误以新为准；未解决冲突、不同语境和正文/评论差异按真实日期并列。
- **场次溯源**：论断标注来源场次、直播日期或公众号真实发布日期；文章发布日期、直播日期、整理日期与研究日期互不冒充。
- **原话保真**：引用只截取不改写；付费文引文以原 PDF 页图为最终依据。
- **三级应用许可**：A 类学说解释允许；B 类限定性自我观察与官方低风险产品说明允许；C 类诊断、方药剂量、个体治疗以及精神/重症产品分流禁止。
- **统一输出与退出**：健康与产品问题使用“观察整理｜模型解释（标签）｜不能判断｜低风险下一步｜停止/退出”，先按 04 排风险，用户在任意步骤均可退出。
- **医疗红线**：全库不输出诊断、方药剂量、个体治疗或停药/接种建议；继承他本人"无证不问诊不荐药"的边界；每答文末固定免责框。
