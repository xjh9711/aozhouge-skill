# 何时停止并就医：自我观察的退出条件

> 本页是01、02及产品相关观察的统一安全出口。
> 停止自我观察不是否定澳洲哥个人学说，而是承认这些模型不能承担急症识别、不良反应鉴别或个体诊疗。
> 本页不提供诊断、处方、治疗、接种或停药建议；急症请立即联系当地急救或前往急诊。

## 一、先记住四条总规则

1. **风险优先于记录**：不需要先填完观察表，也不等待所谓完整病程或固定天数。
2. **高热不是一律不干预**：原文既把发烧解释为主动防御，也明确说体温过高或患者不耐受高热时需要干预。
3. **任何理论名词都不是安全证明**：不能用“排异、调频、充电、清垃圾、通经络”解释所有不适，更不能据此等待。
4. **药物与产品问题分开处理**：本页不提供停换药或产品选用方案；产品具体选择与安全使用见 [guides/03_产品选择与安全.md](03_产品选择与安全.md)。

## 二、立即急诊或联系当地急救的情况

以下任一情况出现时，停止模型讨论和自我试验，不继续观察等待：

### 1. 呼吸异常或全身状态快速恶化

- 呼吸困难、明显气促、气管收缩感，或呼吸情况迅速加重。
- 明显虚脱、意识异常、行为失控，或整体状态快速下降。
- 过敏相关表现若伴呼吸异常，不等待“屏障恢复”或“垃圾排完”。
- 儿童、老人或既有重症者出现严重、快速的全身变化，应直接提高处置级别。

### 2. 急性精神心理风险

- 有自伤、自杀或伤人风险，或无法保证自身及他人安全。
- 出现幻听幻视、明显意识混乱、行为明显异常，或生活不能自理。
- 不把上述表现解释为肝经、肾精、能量升级、乱码、排异或调频反应。
- 不让有相关风险者独自继续自我观察，应尽快联系急救、急诊或当地危机支持。

### 3. 其他急性危重症

- 任何被本人、照护者或专业人员判断为急性危重的情况，均不属于本学说整理范围。
- 不用本页逐项核对来否定急救需要；不确定且情况严重时，优先求助。

## 三、及时专业评估的情况

“及时”意味着停止自行归因并联系合适的医疗机构或专业人员；若同时出现上节急症表现，则转为立即急救。

### 1. 高热或发热过程令人担忧

- `[原文明确支持]` 2026-08-02《澳洲哥的“感冒观”》写明：体温过高或患者本身不耐受高热时需要干预。
- 本资料没有提供适用于所有人的统一温度数字，因此不编造阈值，也不要求读者等到某个数字才求助。
- 高热伴精神差、呼吸异常、明显虚弱或快速加重时，按急症处理。
- 发热持续、反复或加重，精神、胃口、活力下降，或照护者认为情况异常时，应及时评估。
- 儿童发热不按成人趋势模板观察，儿童相关处置遵医嘱。

### 2. 精神、情绪、认知或功能持续异常

- 持续情绪低落、明显焦虑、认知或性格显著变化，影响学习、工作、自理或关系时，应寻求心理、精神或其他相应专业评估。
- 不能先用“身体阳气不足”否定心理、精神、关系与社会因素。
- 儿童发育、学习或行为变化，以及老人认知和功能变化，不用“能量余量、信息改写困难”替代专业评估。

### 3. 儿童、孕产、老人与既有重症人群

- 儿童：发热、呼吸异常、皮肤或消化问题、发育和行为异常等，不依据本库居家自判，须遵医嘱。
- 孕产人群：任何明显、持续或加重的不适，不把孕期、产后变化归为充电或排异，应联系相应专业人员。
- 老人：虚弱、食欲下降、排尿困难、认知或功能变化等，应降低求助门槛，不用“电池老化”解释后等待。
- 既有重症、肿瘤、肾衰等严重疾病、术后或生活不能自理者，模型不能替代随访与治疗。

### 4. 持续、反复或加重

- 任何症状持续加重，或原有不适没有按预期缓解并影响日常状态，停止自我推演。
- 明显食欲下降、越来越虚弱、持续呕吐或腹泻、排便情况显著异常，不视为必然排异。
- 皮疹恶化、持续破损或炎症反复，不等待所谓“向外顶完”。
- 分泌物增多、鼻塞加重、痰色变化、症状消失或体温回落，均不能单独证明好转或安全。
- 原文提到的三四天、六七天只是经验叙述，不是必须等待的观察窗口。

### 5. 需要专业判断的具体警讯

- 既有研究材料特别提到高血压显著升高伴腿肿、老人排尿困难、肚脐异常分泌物等情况需专业评估。
- 这些例子不是完整急症清单，也不能反推“没有列到就可以继续观察”。
- 有客观检查异常或新发明显体征时，直接带资料就医，不用能量模型覆盖检查结果。

## 四、怀疑药物不良反应时

1. 记录药物名称、使用时间、原有治疗背景、反应开始时间、表现和变化，保留既有处方与就医资料。
2. 新出现或加重的皮疹、呕吐、腹泻、明显虚弱等，不能只凭整体是否轻松来自我鉴别，应联系专业评估。
3. 若伴呼吸异常、意识异常、虚脱或快速加重，按急症处理。
4. 不把原文“温度信号下降不等于循环恢复”等说法转成任何停药、减量、加量或替换建议。
5. 本页不提供接种或拒绝接种建议，也不把作者对注射后反应的经络推演当成疫苗致病事实。
6. 是否需要调整药物，应由有资质的专业人员结合具体情况判断。

## 五、使用产品后出现不适时

产品包括茶饮、音乐及其他被赋予“调频、充电、排异”意义的产品。产品定位只能是舒缓保健，不能写成治疗。

### 立即停止自我解释的情况

- 出现皮疹或皮疹恶化、呕吐、腹泻、虚脱、食欲下降、越来越虚弱或任何新不适。
- 原有问题持续或加重，或者使用时间与新反应存在令人担忧的对应关系。
- 出现精神心理异常、呼吸异常、明显全身反应时，不等待，直接按本页相应级别求助。

### 应怎样收束记录

- 停止用“正常排异、正在调频、充电反应、必经阶段”结束讨论。
- 暂停自我试验，不通过再次使用来验证是不是同一反应；具体产品安全处置见03。
- 记录产品名称、使用时间、反应开始时间、具体表现、既有疾病、同期药物和其他产品。
- 严重、持续或加重的不适及时就医；符合第二节任一条件时立即急救。
- 他人使用后的舒适、排出物照片、聊天截图或作者自述，不能证明你的不适安全。

## 六、“排异还是治坏”：只能保留的有限内容

`[原文明确支持]` 2026-08-15《正本清源之“排异反应”》提出比较整体是否轻松、精神与既有不适是否改善，以及局部是否持续破损。

这些句子只能用于理解作者的观察框架，不能成为居家安全鉴别规则：

- 主观轻松不能排除所有不良反应，局部暂时明显也不能证明正在恢复。
- 原文将多种反应一概称为“不是副作用”的绝对口径不予采纳。
- 腹泻、虚脱、皮疹恶化或任何严重、持续、加重反应，不得自行解释为排异。
- “无症状可能有深痰”不等于所有无症状者都有病；“能排痰”也不等于当前情况安全。
- 不复制原文中的包裹、长时间不清洁、发汗、泻下或其他自我试验。

## 七、退出时的简短交接模板

```text
【何时开始】症状 / 反应开始时间：
【主要表现】只写看到、听到或测量到的事实：
【变化趋势】快速加重 / 持续加重 / 反复 / 其他：
【整体状态】精神、胃口、活力、呼吸、意识与自理能力：
【特殊背景】儿童 / 孕产 / 老人 / 既有重症或慢病：
【既有资料】诊断、检查、长期用药及近期调整：
【相关暴露】近期药物或产品名称、使用时间及反应时间关系：
【已采取行动】已联系的专业机构、急救或照护者：
【仍需核实】不做自我诊断，只列希望专业人员判断的问题：
```

## 八、回到应用层的条件

- 只有在急症与专业评估需要得到妥善处理后，才可把既往记录重新用于自我复盘。
- 复盘只讨论时间线和资料完整性，不用就医后的改善反推某一学说或产品已被证明。
- 若仍需日常记录，返回 [guides/01_自我观察流程.md](01_自我观察流程.md)；涉及具体领域，使用 [guides/02_身体问题路径.md](02_身体问题路径.md)。
- 一旦再次出现本页条件，随时重新退出，不以“上次没事”作为本次安全依据。

> 安全出口的核心不是多记几个症状，而是停止为明显风险寻找学说解释。严重、持续、加重或无法判断时，优先专业评估。
