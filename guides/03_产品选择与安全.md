# 产品使用与安全

**核心边界：产品只按“舒缓保健、不治病”定位理解，不用于诊断、治疗或替代就医；任何症状与曲目、茶饮的对应都只是体验或讲解里的说法，不是使用者的诊断结论。[产品主张]**

我跟你说，产品不是药，也不是诊断工具，对不对：我能告诉你我体验过什么、直播里怎么讲过，却不能据此判断你的病因、疗效或治疗方案。

## 音乐选择的依据

音乐选择只按两类材料：`sources/产品与体验/` 的音乐AI个人体验文档（2026-10 收录，个人体验），以及直播、私密课里的症状描述。两者都是“体验与讲解的对应”，不是适应证清单。

## 使用守则（用户确认保留）

> 以下六条是用户确认保留的选曲口径；依据只有体验文档（2026-10）与直播、私密课原话。官职曲＝该经以“某之官”命名的那首（如仓廪之官、中正之官）；打底曲＝州都之官／太阳寒水这类公共保养入口。

1. **最明显症状进对应专区。** 看“身上什么感觉”，对上才试该曲；对不上或说不清，听该区官职曲兜底；助眠区例外，以主观安神、暖感试听自选。
2. **一证一曲。** 对症曲一次只听一首，多首混听气机会乱；官职曲与打底曲可轮听，但轮听≠同时叠放，≠越多越好。
3. **先无伤后对症，先脾胃后其他。** 一次只变一个变量，见改善再进下一首；改善只作主观记录，不据此认定疾病痊愈，不把多个专区拼成自诊套餐。
4. **抓主证，不数症状。** 只认领最典型的一行；症状横跨多区别硬归并；可先以脾胃区官职曲兜底，同时尽早面诊，兜底不能替代面诊。
5. **少听体会，不适即停。** 不硬听、不久听、不猛听，不因免费随意多听；激烈澎湃类“一人一音”，切莫分享硬听；“一天1—2遍”只限该类别，不外推成全曲库统一剂量。
6. **宣传语不是安全保证。** 文案里的“任何人都合适”“不分年龄”“百搭没禁忌”“心脏不舒服多听没坏处”“用了没有错”等仅作文案归档，实际以个体风险、停止规则和专业评估为准。

复杂、多系统、寒热错杂、虚实夹杂的情况不自行套曲目；需要复杂辨证的不要听音乐，退出自助，转专业评估。

## 特殊人群与风险退出

| 情形 | 处理 |
|---|---|
| 儿童 | 不自行选曲、选茶或试用产品，遵医嘱；高热、精神状态异常或其他急性情况及时就医 |
| 孕期、哺乳期 | 不依据直播或个人体验自行使用，先遵专业医疗意见；不让产品替代孕产期评估 |
| 心脏疾病或心脏不适 | 不进入产品自助分档；胸痛、胸闷伴冷汗、呼吸困难或疼痛放射等情况立即就医 |
| 精神症状 | 幻听、幻视、妄想、明显精神行为异常或自伤伤人风险，立即转精神心理／医疗专业评估；紧急风险立即求助 |
| 复杂或重症问题 | 多系统复杂问题、急危重症、症状持续或明显加重时退出产品路径，及时专业评估或就医 |

出现以上任一情形，均不先试产品、不等待体感验证，也不以产品延误诊疗。一般使用中若原有症状持续、严重或加重，同样停止并退出。
