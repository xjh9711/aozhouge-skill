# 产品选择与安全：先选任务，不先选病名

我跟你说，选这类产品就像选手机应用：先弄清自己要的是音乐放松、了解经络，还是日常保养，不能一看见“上火”“结节”“幻听”这些词，就把商品当成治疗程序，对不对？

**先给结论：成人、无急性或明显不适的放松体验，可以阅读并谨慎参考有出处的产品方通用说明；任何疾病诊断、方药剂量、儿童重症、高热或精神症状，都不进入产品选择路径。**

本指南只整理现有材料。现有材料中**未见带版本号、发布日期和完整禁忌的现行官方说明书**，所以下文写“产品方历史说明”或“直播历史口径”，不冒充当前官方结论。产品迭代后，应以可核验的当版书面说明为准；拿不到，就不能补写用法。

## 先分清四种话

| 材料类型 | 本指南如何使用 | 不能推出什么 |
|---|---|---|
| 产品方书面说明 | 可恢复有原文、非个体化、低风险的通用流程或聆听参数，并注明版本、日期与退出条件 | 不能推出治疗有效、人人安全或现在仍是同一版本 |
| 直播／课程中的产品方历史口径 | 可说明当时的产品定位、设计流程和明确禁忌 | 不能自动变成现行官方说明书 |
| 个人体验、连线、聊天截图 | 只证明某人这样感受或转述 | 不能作为选曲、选购、剂量、疗效或安全依据 |
| 疗效宣传、绝对安全承诺、按疾病分档 | 仅作风险话术归档 | 不进入实际使用建议 |

**证据等级只表示来源可追溯性，不表示临床有效性：**

| 等级 | 含义 |
|---|---|
| L1 | 有可回查的产品方书面材料；版本不全时仍只算历史说明 |
| L2 | 有可定位的直播、课程或公众号产品方口径；日期缺失会另标 |
| L3 | 个人体验、读者或连线自述；不作选用依据 |
| X | 疗效宣传、绝对安全、疾病或精神症状产品分档；不采用 |

## 使用边界总表

| 需求或情形 | 是否进入产品路径 | 边界 |
|---|---|---|
| 了解经络、能量等学说 | 可以 | 只作澳洲哥个人学说，[内证断言]不是科学或中医共识，体感不能证明理论或疗效 |
| 成人一般放松、日常情志调养 | 可以有条件进入 | 只参考低风险通用说明；不追求治病，不猛听、猛喝，不以产品代替休息和诊疗 |
| 普通茶饮的风味与品质选择 | 可以 | 普通茶不等于“黑科技茶”，不谈疾病适应证，不补冲泡剂量或频次 |
| 按症状给自己诊断“火型”“经络堵塞”后速配产品 | 不进入 | 这是自诊与疗效路径，尤其寒热错杂、持续症状不能居家分流 |
| 个体诊断、方药剂量、食疗加减比例 | 不进入 | 本指南不提供，也不从案例中反推 |
| 儿童高热、儿童重症、老人重症或其他急性危重情况 | 立即退出 | 及时专业评估或就医；不先试音乐、茶、玉佩或防火墙 |
| 幻听、幻视、被害妄想、明显精神行为异常 | 立即退出 | 及时精神心理／医疗专业评估；防火墙和其他产品不得参与分档 |
| 使用中明显不适，或原有症状持续、严重、加重 | 停用并退出 | 不解释为“排病”“排异”或“必经反应”；按[《何时停止并就医》](04_何时停止并就医.md)处理 |

## 先选任务，不先选病名

你看啊，同样是“我想舒服一点”，任务不同，出口就不同：

| 实际任务 | 合适动作 |
|---|---|
| 成年人只想安静放松、体验音乐 | 选择一般放松场景，以舒适为限；不查病名配曲，不承诺改善疾病 |
| 想理解“经络调频”“一人一方”的产品设计 | 阅读其模型和历史流程即可；体感是主观输入，不是验收疗效的仪器 |
| 想做日常保养 | 先确认是否有当版成分、标签、禁忌和书面说明；资料不全就不自行补参数 |
| 想处理高热、心脏不适、持续疼痛、明显失眠或其他疾病问题 | 不走商品速配，转专业评估 |
| 想给孩子、孕产人群、慢病或重症家人试用 | 不依据本指南自行试用，遵医嘱 |

| 单曲、传统曲目与平台专区被用于经络体验和一般保养。[产品主张] | 成人放松不按个人体验笔记或疾病名单选曲；“某官”分区只是产品组织方式，不是人人适用保证 | 2026-08-26①与2026-08-29上午直播：反对单曲狂听、猛听，强调动态调整；2026-10收录图版另有降火分类与一般聆听参数 | 不用“无害”“百搭”“无禁忌”作安全保证；心脏症状、发热、精神症状及持续加重退出 | L1+L2；曲目功效未独立验证 |

### AI 定制流程怎样理解

1. **先确认任务**：这里只描述产品方当时的系统流程，不由本指南收集症状、判断经络或给个体配曲。
2. **输入主诉**：2026-08-26①直播的产品流程是输入主诉；2026-08-29上午补充“主诉精准、忌小作文”。这只是输入偏好，不提供症状模板。
3. **生成专属内容**：由当时的系统生成，不把直播间大众公放与定制曲混为一谈。
4. **反馈后更新**：产品方主张按身体变化和反馈更新；现有材料不支持一个适用于所有人的固定更换周期，不恢复“三天一换”等旧话术。
5. **不自行加强**：不把多曲叠加、长时间循环或猛听当成“加强版”。“单曲狂听像乱吃药”是产品方自己的风险警示。

### 有书面出处的一般聆听说明

以下来自用户提供图版《音乐产品选取指南》中的《降火疗愈乐曲·选曲指南》转录，**2026-10为收录时间，不是发布日期；未见版本号**。它们只是产品方历史通用口径，不是个体建议，也不能外推到全部AI曲、所有专区或儿童。

| 项目 | 产品方图版原口径 | 本指南的安全限定 |
|---|---|---|
| 音量 | “宜小不宜大，以舒适为度” | 作为成人一般放松的低风险说明保留；不舒适就调停，不追求体感强度 |
| 时长与频率 | “每日30分钟” | 只代表该图版，不是所有产品的统一时长，也不是必须完成的打卡任务 |
| 周期 | “坚持2–4周为一周期” | 不是疗程或起效承诺；期间症状持续、严重或加重，应停用并专业评估，而非坚持满周期 |
| 呼吸配合 | “深长呼气”被宣称可增强“降”的效果 | 只记录图版说明，不认可其增效主张；自然舒适即可，不强迫呼吸，不适即停 |
| 使用心态 | 图版定位日常情志调养；2026-08-29上午直播又强调放松、反对拼命抓取 | 把音乐当陪伴，不当治疗任务，不以麻、胀、热、头晕等体验验证疗效 |

图版的“三步框架”是**先看火型→区分实火、虚火与寒热错杂→速配曲目**。这里只恢复其组织框架，不恢复按口腔溃疡、干咳、便秘、心悸等症状自行诊断和逐曲速配；图版自己也提示“上热下寒不要单纯降火”以及“症状持续或加重请及时就医”。按心火、肝火分配的钟点也不写成所有人的通用收听时间。

另见摘要所称《薪火音乐选曲指南》的“先调后补／必听／曲目分区”三步选曲框架。**现有材料只有摘要，未见指南原文、日期、版本和‘必听’清单**，所以不能补成购买顺序或必听方案。

### 个人体验不能变成选曲依据

《澳洲哥音乐AI个人体验》及2026-10收录笔记的作者明确声明：仅为个人体验，不可作为医学建议或平台官方建议。其中的专区曲目、疾病联想、“任何人合适”“百搭无禁忌”、症状好转和力猛比较，全部只属L3。

因此，本指南不列“某症状对应某曲”的清单，也不把助眠、湿疹、灰指甲、腺样体、心脏不适或儿童发烧的个人叙述转成推荐。

## 茶饮、普通茶与咖啡

| 官方／产品方定位 | 选择原则（非疾病适应证） | 官方／历史用法及来源日期 | 不适用与停用 | 证据等级 |
|---|---|---|---|---|
| 自研茶被定位为成人保养、“加能、疏通”的产品；轻产品与按体质定制高阶产品在公众号中仍属未来规划。[产品主张] | 不按结节、掉发、失眠、“倔”或认知变化选茶；风里、陌上红等宣传不能替代当版成分与标签 | 2026-07-18直播称“小朋友不要喝茶”、茶为成人保养品；2026-08-31直播明确“水仙茶经期停饮” | 儿童不进入；水仙茶经期停饮不能外推成其他茶的完整禁忌；孕产、慢病、正在用药者先遵专业意见；饮后明显不适或加重即停 | L2；茶友改善自述为L3，功效未证 |
| 普通茶、咖啡不是本指南所称自研产品，只用于理解消费边界 | 好茶不以越贵、越提神为标准；文章提出山场→品种→工艺，以及“醒神而不躁神” | 公众号《同样能让人“精神起来”，咖啡、茶和附子到底有什么不同？》现有文本未录发布日期；只给品质框架，没有自研茶冲泡或饮用方案 | 极度疲劳时不用咖啡或浓茶屏蔽信号继续熬夜、工作或运动；心慌、手抖等明显不适停止饮用，持续或严重者评估 | L2；不形成剂量或频次建议 |

**茶饮资料不足的部分就空着**：不补每日杯数、每次克数、浓度、水温、疗程、搭配比例，也不把“通大便”“保持60／70分”当效果承诺。所谓60／70分是作者比喻，不是健康量表或就诊分诊工具。

茶后若出现持续或加重的便秘、“上火”、腹泻、心慌、失眠等，不自行加减其他本草“微调”，先停用；需要时转专业评估。儿童不因为家长觉得温和就试饮。

## 三个决策示例

| 情境 | 决策 | 理由与出口 |
|---|---|---|
| 成年人只想放松体验，没有急性或明显不适 | 可在一般音乐放松范围内谨慎参考产品方历史通用说明，音量以舒适为度；如参考2026-10收录图版，其“每日30分钟、2–4周”也只是该图版口径 | 不按病名选曲，不追求排病感，不承诺效果；任何明显不适即停，持续或加重退出 |
| 家长因孩子高烧询问音乐、茶、玉佩或防火墙 | **不进入任何产品路径，及时儿科／医疗专业评估；情况严重立即就医** | 产品不能替代儿童发热评估，不等待一个收听周期，不用“排异”解释精神状态或症状变化 |
| 用户出现幻听，或使用后问题持续加重 | **立即停止产品试用并转专业评估；幻听直接退出产品分档** | 防火墙3.0、玉佩护持、AI音乐都不是精神症状处置；有自伤、伤人或无法保证安全的风险时立即紧急求助 |

更完整的停用、复评与就医边界见[《何时停止并就医》](04_何时停止并就医.md)，本篇不重复展开。需要整理产品名称、使用时间与反应时间线时，返回 [guides/01 的最小基线](01_自我观察流程.md)；停用与就医仍按[04](04_何时停止并就医.md)。

## 购买或使用前的最后核对

- 我现在的任务是成人放松、了解学说或一般消费，还是已经在处理疾病？后者先退出。
- 这句话来自产品方书面说明、直播历史口径，还是个人体验与疗效宣传？
- 有没有可核验的当版版本、发布日期、成分／曲目说明、禁忌和停止规则？
- 我是否把“有人有效”“无害”“百搭”“排病”误读成了自己的安全保证？
- 一旦出现不适、持续加重或精神症状，我是否知道应停用并转专业评估？

啊，声明一下——我不问诊不荐药，只讲原理。真正低风险的选择，不是找到一款“什么都能调”的产品，而是知道什么时候不用产品。

> 固定免责框以 `SKILL.md` ⑩为唯一规范源，本指南不另设版本；实际回答时每答文末仅附加一次。
