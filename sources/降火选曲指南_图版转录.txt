== 三步法则：先看火型 ==

1. 心火旺（口腔溃疡、舌尖红、心烦失眠）
2. 肝火旺（目赤、易怒、头痛眩晕、两胁胀痛）
3. 肺火（干咳无痰或黄痰、咽喉肿痛、鼻衄）
4. 胃火（口臭、牙龈肿痛、便秘、消谷善饥）
5. 肾虚火（潮热盗汗、耳鸣、腰膝酸软）
6. 脾湿/痰热（口黏、湿热、痰多胸闷）

== 第二步：找到对应"火区"（注意区分） ==

- 实火 vs 虚火：突发的、剧烈的多为实火；长期慢性的、隐隐作痛的常为虚火
- 寒热错杂型：上热下寒（上火但下肢冰冷）不要单纯降火

== 第三步：速配 ==

- 心火上炎/失眠：子夜清、清心调、安神曲
- 肝阳上亢/易怒：角调式乐曲、疏肝解郁类
- 肺燥热/干咳：商调式、润肺曲目
- 胃火旺/口臭：宫调式、健脾和胃类

== 分区曲目推荐 ==

【心】火型：心火（舌尖红、口舌生疮、心烦、失眠、小便黄）
- 紫竹调 / 汉宫秋月：清心安神，适合心烦意乱、入睡困难
- 平湖秋月 / 高山流水：滋阴降火，适合虚烦不眠、口舌生疮反复
- 梅花三弄：清心除烦，适合心火旺导致的烦躁不安
- 夕阳箫鼓：宁心安神，适合思虑过度、心悸失眠
适用症状：心烦、失眠、口腔溃疡、舌尖红/生疮、小便短赤

【肝】火型：肝火（目赤、易怒、头痛、胁痛）
- 胡笳十八拍 / 广陵散：疏肝理气，适合肝郁化火、暴躁易怒
- 阳春白雪 / 平沙落雁：平肝潜阳，适合肝阳上亢、头晕目眩
- 渔樵问答：舒缓情志，适合长期压抑、肝气郁结化火
- 高山流水：清肝降火，适合目赤肿痛、头痛
适用症状：易怒、目赤、头痛眩晕、两胁胀痛、口苦

【脾】火型：湿热脾火（口黏口臭、脘腹胀满）
- 十面埋伏：注意！此曲激昂，湿热重者少用，只取其"宣散"之气短期听
- 阳春白雪 / 深宫秋月：健脾化湿，适合口黏、脘闷、食欲差
- 塞上曲：和胃化浊，适合湿热困脾、口中黏腻
适用症状：口黏口臭、脘腹胀满、身体困重、湿热痰多

【肺】火型：肺火（干咳、咽痛、鼻衄）
- 阳关三叠 / 阳春白雪：商调式，润肺降气，适合干咳咽干
- 长清 / 鹤鸣九皋：清肺润燥，适合秋燥咳嗽、咽喉肿痛
- 白雪：清宣肺气，适合肺热咳喘、鼻衄
适用症状：干咳少痰/黄痰、咽喉肿痛、鼻干鼻衄

【胃】火型：胃火（口臭、牙龈肿痛、便秘）
- 春江花月夜：宫调式，清胃泻火，适合胃火炽盛、口臭便秘
- 月儿高 / 寒鸦戏水：清热和胃，适合牙龈肿痛、口渴喜冷饮
- 平湖秋月：滋阴清胃，适合虚火牙痛
适用症状：口臭、牙龈肿痛出血、便秘、口渴多饮

【肾】火型：肾虚火（虚火上炎、潮热盗汗）
- 二泉映月：滋肾降火，适合肾阴不足、虚火上炎之咽干耳鸣
- 寒鸦戏水 / 平沙落雁：滋阴潜阳，适合潮热盗汗、腰膝酸软
- 梅花三弄：引火归元，适合上热下寒、虚阳上越
适用症状：潮热盗汗、耳鸣耳聋、腰膝酸软、咽干口燥

【脾湿（痰热）— 特别区分】火型：痰热互结（口黏苔腻、胸闷痰多）
- 忆故人：化痰开郁，适合痰气交阻、胸闷不舒
- 醉渔唱晚：化湿醒脾，适合湿浊内阻、痰多困重
适用症状：痰多、口黏、胸闷、苔腻

== 综合·灭火用法 ==

1. 辨清虚实：实火猛降、虚火慢调，上热下寒需引火归元
2. 最佳聆听时间：心火晚间 21:00–23:00（三焦经/心包经当令前）；肝火清晨或 23:00 前入睡配合
3. 音量：宜小不宜大，以舒适为度
4. 配合呼吸：深长呼气可增强"降"的效果
5. 疗程：每日 30 分钟，坚持 2–4 周为一周期
